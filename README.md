# Snake Game (스네이크 게임)

Java Swing을 기반으로 개발한 클래식 스네이크 게임으로, Java 프로그래밍 기말 프로젝트입니다.

## 프로젝트 소개

이 프로젝트는 시작 메뉴, 점수 시스템, 최고 점수 로컬 저장, 사운드 효과, 속도 증가 등의 기능을 포함한 비교적 완성도 높은 스네이크 게임을 구현하였습니다. 객체지향 설계를 적용하여 코드 구조가 명확합니다.

## 주요 기능

- 시작 메뉴 화면
- 방향키로 뱀 이동 제어
- 먹이를 먹으면 뱀의 몸이 길어지고 점수 증가
- 점수가 올라갈수록 게임 속도가 점차 빨라짐
- 벽이나 자신의 몸에 부딪히면 게임 종료
- 게임 종료 후 스페이스바로 다시 시작 가능
- 최고 점수를 로컬 파일에 저장 (프로그램 종료 후에도 유지)
- 먹이를 먹을 때와 게임 종료 시 사운드 효과

## 기술 스택

- 언어: Java
- GUI: Java Swing
- 사운드: javax.sound.sampled
- 개발 도구: Eclipse

## 프로젝트 구조

```
SnakeGame
├── src/com/snake
│   ├── Main.java              # 프로그램 진입점
│   ├── GameFrame.java         # 게임 메인 창
│   ├── GamePanel.java         # 게임 메인 패널 (핵심 로직)
│   ├── Snake.java             # 뱀 로직
│   ├── Food.java              # 먹이 생성 및 그리기
│   ├── ScoreManager.java      # 점수 및 최고 점수 관리
│   └── SoundManager.java      # 사운드 관리
├── sounds
│   ├── eat.wav                # 먹이 섭취 사운드
│   └── gameover.wav           # 게임 오버 사운드
├── README.md
└── highscore.txt              # 최고 점수 저장 파일 (실행 후 자동 생성)
```

## 실행 방법

1. Eclipse에서 본 프로젝트를 엽니다.
2. `Main.java`를 찾아 우클릭 → Run As → Java Application

## 조작 방법

- **방향키**: 뱀의 이동 방향 제어
- **스페이스바**: 메뉴 화면에서 게임 시작 / 종료 화면에서 다시 시작

## 프로젝트 설계 설명

### 1. 주제 선정 이유
클래식 스네이크 게임을 선택한 이유는 로직이 명확하고 구현 난이도가 적당하며, 메뉴, 점수 시스템, 사운드, 속도 변화 등의 기능을 추가하여 완성도를 높일 수 있어 기말 프로젝트로 객체지향 프로그래밍과 GUI 개발 능력을 보여주기에 적합하기 때문입니다.

### 2. 핵심 클래스 설계

| 클래스명 | 역할 |
|---------|------|
| Main | 프로그램 시작 진입점 |
| GameFrame | 게임 창 생성 |
| GamePanel | 게임 메인 루프, 그리기, 키보드 리스너, 상태 관리 |
| Snake | 뱀의 몸 관리, 이동, 충돌 감지 |
| Food | 먹이의 랜덤 생성 및 그리기 |
| ScoreManager | 현재 점수와 최고 점수의 관리 및 파일 입출력 |
| SoundManager | 사운드 재생 |
### 3. 게임 상태 관리
열거형 `GameState`를 사용하여 세 가지 상태를 관리합니다.
- MENU: 시작 메뉴
- RUNNING: 게임 진행 중
- GAME_OVER: 게임 종료
